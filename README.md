# BD Food Shop – Frontend

**BD Food Shop** is a simple frontend web application for browsing and purchasing food items online.
It displays available products, their details, and allows users to add items to a cart, update quantities, and proceed through a checkout flow.

This project is built entirely with **ReactJS** and is focused on providing a clean, responsive, user-friendly interface.

---

## 🌐 Live Demo

[https://bd-food-shop.onrender.com](https://bd-food-shop.onrender.com)

---

## ✨ Features

### 🛍️ Product Browsing

- Displays all available food items
- Each item shows name, price, and image
- View detailed product information

### 🔎 Search & Filter

- Search products by keyword
- Filter by category (if included)

### 🛒 Cart Functionality

- Add items to cart
- Update item quantity
- Remove items
- Dynamic price updates

### 💳 Checkout UI

- Displays order summary
- User enters checkout information (if supported)

### 📱 Responsive Design

- Fully responsive layout for mobile, tablet, and desktop
- Smooth and clean UI

## ⚙️ Installation & Setup

### 1️⃣ Clone the repository

```
git clone https://github.com/ayaj-uddin-24/bd-food-shop
cd bd-food-shop
```

### 2️⃣ Install dependencies

```
npm install
```

### 3️⃣ Start the development server

```
npm run dev
```

The frontend will open at: `http://localhost:5173/`
